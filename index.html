Fine-tuning

When a small trained model beats a prompt, and when it doesn't, measured on accuracy, safety, latency and cost.

Fine-tuning · Model evaluation

NovaCell Intent Router: prompt or fine-tune?

Should a support assistant handling ~150,000 messages a month sort customer messages with a prompted LLM or a small fine-tuned model? I labelled 560 synthetic customer messages across 8 intents, including a must-go-to-an-agent class, fine-tuned a 22M-parameter MiniLM on CPU in 35 seconds, and compared it with a keyword baseline and prompted gpt-oss models on accuracy, safety recall, latency and 12-month cost.

  • Fine-tuned: 95.6% clean / 88.8% messy accuracy, ~7 ms
  • Prompted gpt-oss-120b: 93.8% clean / 98.8% messy, 100% agent handoffs caught on messy messages
  • Decision: keep the prompt ($289 vs $954 a year); fine-tuning pays off only above ~0.7M messages a month

PyTorch · MiniLM-L6 · scikit-learn baseline · Groq gpt-oss-120b / 20b · cost model
